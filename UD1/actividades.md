## Actividad 1 Licencias del software utilizado. 

Visual Studio Code

Visual Studio Code tiene dos partes que hay que distinguir. El código fuente de Code - OSS utiliza la licencia MIT, que es una licencia de software libre y permisiva. Sin embargo, la versión oficial de Visual Studio Code distribuida por Microsoft utiliza una licencia propietaria de Microsoft.

Git

Git utiliza principalmente la licencia GNU General Public License versión 2 (GPLv2). Es una licencia de software libre de tipo copyleft, que permite utilizar, modificar y distribuir el software, pero establece determinadas condiciones para la distribución de versiones modificadas.


GitHub

GitHub no tiene una única licencia de software como Git o Code - OSS, ya que es principalmente una plataforma y servicio en línea. Su utilización está regulada por los Términos de Servicio de GitHub. Además, cada repositorio alojado en GitHub puede utilizar una licencia diferente, elegida por sus autores.

Tipo: servicio propietario regulado mediante términos de servicio.


Clasificación final

Visual Studio Code: licencia propietaria de Microsoft (la distribución oficial) / MIT (Code - OSS).

Git: GNU GPLv2, licencia de software libre de tipo copyleft.

GitHub: servicio propietario regulado por sus Términos de Servicio.

## Actividad 2 Requisitos de Visual Studio Code.

> # Sistemas Operativos Compatibles

    - Windows: Windows 10 y Windows 11 (solo versiones de 64 bits).
    Las versiones antiguas como Windows 7, 8 y los sistemas de 32 bits ya no reciben soporte.
 
    - macOS: Versiones recientes de Apple (soporta procesadores Intel y Apple Silicon como el M1/M2/M3).
 
    - Linux: Distribuciones modernas como Ubuntu, Debian, Fedora y Red Hat.
 
> # Requisitos Mínimos de Hardware
 
    - Procesador (CPU): 1.6 GHz o más rápido.
 
    - Memoria RAM: 1 GB como mínimo.
 
    - Almacenamiento: Menos de 200 MB para descargar y unos 500 MB de espacio libre en el disco duro.
 
> # Versiones Disponibles
 
Al ir a la página de descargas de VS Code encontrarás dos tipos de versiones principales
 
    -Versión Estable (Stable): Es la que usa todo el mundo. Es segura, no tiene fallos graves y se actualiza una vez al mes.
 
    -Versión de Pruebas (Insiders): Es una versión que se actualiza todos los días con herramientas nuevas que los creadores están probando, pero puede tener pequeños errores.
